# 2.3.2 补码加法

对于补码加法，我们必须确定当结果太大（为正）或者太小（为负）时，应该做些什么。给定在范围 -2<sup>w-1</sup> ≤ x, y ≤ 2<sup>w-1</sup> - 1 之内的整数值 x 和 y，它们的和就在范围 -2<sup>w</sup> ≤ x + y ≤ 2<sup>w</sup> - 2 之内，要想准确表示，可能需要 w + 1 位。就像以前一样，我们通过将表示截断到 w 位，来避免数据大小的不断扩张。然而，结果却不像模数加法那样在数学上感觉很熟悉。定义 x +<sup>t</sup><sub>w</sub> y 为整数和 x + y 被截断为 w 位的结果，并将这个结果看做是补码数。

**原理：补码加法**

对满足 -2<sup>w-1</sup> ≤ x, y ≤ 2<sup>w-1</sup> - 1 的整数 x 和 y，有：

| x +<sup>t</sup><sub>w</sub> y | 条件 | 情况 |
| --- | --- | --- |
| x + y - 2<sup>w</sup> | 2<sup>w-1</sup> ≤ x + y | 正溢出 |
| x + y | -2<sup>w-1</sup> ≤ x + y < 2<sup>w-1</sup> | 正常 |
| x + y + 2<sup>w</sup> | x + y < -2<sup>w-1</sup> | 负溢出 |

（2.13）

图 2-24 说明了这个原理，其中，左边的和 x + y 的取值范围为 -2<sup>w</sup> ≤ x + y ≤ 2<sup>w</sup> - 2，右边显示的是该和数截断为 w 位补码的结果。（图中的标号“情况 1”到“情况 4”用于该原理形式化推导的案例分析中。）当和 x + y 超过 TMax<sub>w</sub> 时（情况 4），我们说发生了正溢出。在这种情况下，截断的结果是从和数中减去 2<sup>w</sup>。当和 x + y 小于 TMin<sub>w</sub> 时（情况 1），我们说发生了负溢出。在这种情况下，截断的结果是把和数加上 2<sup>w</sup>。

两个数的 w 位补码之和与无符号之和有完全相同的位级表示。实际上，大多数计算机使用同样的机器指令来执行无符号或者有符号加法。

![图 2-24 整数和补码加法之间的关系](assets/fig-2-24-twos-complement-relation.jpg)

**推导：补码加法**

既然补码加法与无符号数加法有相同的位级表示，我们就可以按如下步骤表示运算 +<sup>t</sup><sub>w</sub>：将其参数转换为无符号数，执行无符号数加法，再将结果转换为补码：

> x +<sup>t</sup><sub>w</sub> y ≐ U2T<sub>w</sub>(T2U<sub>w</sub>(x) +<sup>u</sup><sub>w</sub> T2U<sub>w</sub>(y))　（2.14）

根据等式 (2.6)，我们可以把 T2U<sub>w</sub>(x) 写成 x<sub>w-1</sub>2<sup>w</sup> + x，把 T2U<sub>w</sub>(y) 写成 y<sub>w-1</sub>2<sup>w</sup> + y。使用属性，即 +<sup>u</sup><sub>w</sub> 是模 2<sup>w</sup> 的加法，以及模数加法的属性，我们就能得到：

> x +<sup>t</sup><sub>w</sub> y = U2T<sub>w</sub>(T2U<sub>w</sub>(x) +<sup>u</sup><sub>w</sub> T2U<sub>w</sub>(y))
>
> = U2T<sub>w</sub>[(x<sub>w-1</sub>2<sup>w</sup> + x + y<sub>w-1</sub>2<sup>w</sup> + y) mod 2<sup>w</sup>]
>
> = U2T<sub>w</sub>[(x + y) mod 2<sup>w</sup>]

消除了 x<sub>w-1</sub>2<sup>w</sup> 和 y<sub>w-1</sub>2<sup>w</sup> 这两项，因为它们模 2<sup>w</sup> 等于 0。

为了更好地理解这个数量，定义 z 为整数和 z = x + y，z' 为 z' = z mod 2<sup>w</sup>，而 z'' 为 z'' = U2T<sub>w</sub>(z')。数值 z'' 等于 x +<sup>t</sup><sub>w</sub> y。我们分成 4 种情况分析，如图 2-24 所示。

1. -2<sup>w</sup> ≤ z < -2<sup>w-1</sup>。然后，我们会有 z' = z + 2<sup>w</sup>。这就得出 0 ≤ z' < -2<sup>w-1</sup> + 2<sup>w</sup> = 2<sup>w-1</sup>。检查等式 (2.7)，我们看到 z' 在满足 z'' = z' 的范围之内。这种情况称为负溢出（negative overflow）。我们将两个负数 x 和 y 相加（这是我们能得到 z < -2<sup>w-1</sup> 的唯一方式），得到一个非负的结果 z'' = x + y + 2<sup>w</sup>。

2. -2<sup>w-1</sup> ≤ z < 0。那么，我们又将有 z' = z + 2<sup>w</sup>，得到 -2<sup>w-1</sup> + 2<sup>w</sup> = 2<sup>w-1</sup> ≤ z' < 2<sup>w</sup>。检查等式 (2.7)，我们看到 z' 在满足 z'' = z' - 2<sup>w</sup> 的范围之内，因此 z'' = z' - 2<sup>w</sup> = z + 2<sup>w</sup> - 2<sup>w</sup> = z。也就是说，我们的补码和 z'' 等于整数和 x + y。

3. 0 ≤ z < 2<sup>w-1</sup>。那么，我们将有 z' = z，得到 0 ≤ z' < 2<sup>w-1</sup>，因此 z'' = z' = z。补码和 z'' 又等于整数和 x + y。

4. 2<sup>w-1</sup> ≤ z < 2<sup>w</sup>。我们又将有 z' = z，得到 2<sup>w-1</sup> ≤ z' < 2<sup>w</sup>。但是在这个范围内，我们有 z'' = z' - 2<sup>w</sup>，得到 z'' = x + y - 2<sup>w</sup>。这种情况称为正溢出（positive overflow）。我们将正数 x 和 y 相加（这是我们能得到 z ≥ 2<sup>w-1</sup> 的唯一方式），得到一个负数结果 z'' = x + y - 2<sup>w</sup>。■

等式 (2.13) 也让我们认出了哪些情况下会发生溢出：

**原理：检测补码加法中的溢出**

对满足 TMin<sub>w</sub> ≤ x, y ≤ TMax<sub>w</sub> 的 x 和 y，令 s = x +<sup>t</sup><sub>w</sub> y。当且仅当 x > 0，y > 0，但 s ≤ 0 时，计算 s 发生了正溢出。当且仅当 x < 0，y < 0，但 s ≥ 0 时，计算 s 发生了负溢出。

图 2-25 显示了当 w = 4 时，这个原理的例子。第一个条目是负溢出的情况，两个负数相加得到一个正数。最后一个条目是正溢出的情况，两个正数相加得到一个负数。

**推导：检测补码加法中的溢出**

让我们先来分析正溢出。如果 x > 0，y > 0，而 s ≤ 0，那么显然发生了正溢出。反过来，正溢出的条件为：1）x > 0，y > 0（或者 x + y > TMax<sub>w</sub>），2）s ≤ 0（见公式 (2.13)）。同样的讨论也适用于负溢出情况。■
