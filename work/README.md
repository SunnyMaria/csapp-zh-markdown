# 整理工作资料

读者请从 [成品目录](../docs/README.md) 开始。

- `output/`：迁移前的输出快照，包括历史成品、草稿、OCR 文本和原始页图。
- `tmp/`：临时文件、原始实验材料和检查图片。
- `sources/`：原始扫描 PDF。
- `tools/`：历史处理脚本，以及可独立运行的成品链接检查脚本。

前三项只在本地保存，由根目录 `.gitignore` 排除；上传仓库不需要这些文件。旧路径在此目录下保持相对关系，运行历史脚本时先进入 `work/`。

后续请直接编辑 `docs/` 中的成品。`tools/prepare_v1.py` 是首次整理使用的迁移工具，仅允许在成品目录不存在时运行，避免覆盖后续修改。
