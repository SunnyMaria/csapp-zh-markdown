# 8.4.1 获取进程 ID

每个进程都有一个唯一的正数（非零）进程 ID（PID）。`getpid` 函数返回调用进程的 PID。`getppid` 函数返回它的父进程的 PID（创建调用进程的进程）。

```c
#include <sys/types.h>
#include <unistd.h>

pid_t getpid(void);
pid_t getppid(void);
```

**返回：** 调用者或其父进程的 PID。

`getpid` 和 `getppid` 函数返回一个类型为 `pid_t` 的整数值，在 Linux 系统上它在 `types.h` 中被定义为 `int`。
