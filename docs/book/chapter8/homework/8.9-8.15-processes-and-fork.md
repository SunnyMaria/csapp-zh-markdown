**家庭作业 8.11**（★）

这个程序会输出多少个 `"hello"` 输出行？

```c

int main()
{
    int i;

    for (i = 0; i < 2; i++)

    printf("hello\n");
    exit(0);
}
```

**家庭作业 8.13**（★）

下面程序的一种可能的输出是什么？

```c
#include "csapp.h"

int main()
{
    int x = 3;

    if (Fork() != 0)
        printf("x=%d\n", ++x);

    printf("x=%d\n", --x);
    exit(0);
}
```
